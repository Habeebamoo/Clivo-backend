# 🚀 Clivo Backend

Backend server for **Clivo** — a modern article publishing platform designed for performance, scalability, and clean architecture.

🔗 https://myclivo.com

---

## ⚙️ Tech Stack

- **Golang** — high-performance backend with strong concurrency support  
- **PostgreSQL** — reliable relational database  
- **Docker** — containerized development and deployment  
- **ImageKit** — image upload, optimization, and CDN delivery  
- **REST API** — structured and scalable communication layer  

---

## 🧠 Architecture

This project follows a clean, maintainable layered architecture:


- **Handler Layer** — manages HTTP requests and responses  
- **Service Layer** — contains core business logic  
- **Repository Layer** — handles database operations  
- **Middleware** — logging, CORS, recovery, and request handling  

The goal is simple: separation of concerns, testability, and scalability.

---

## ✨ Core Features

- 🔐 Authentication system  
- 📝 Article publishing with rich content (text, images, code blocks)  
- 🖼️ Image handling via ImageKit  
- ✅ User verification system  
- 🚫 User restriction and moderation system  
- 🔎 SEO-friendly content structure  
- ⚡ Optimized performance and efficient request handling  
- 🧩 Modular and extensible codebase  

---

## 🚀 Design Philosophy

This backend is built with a focus on:

- **Scalability** — structured to handle growth without rewriting everything  
- **Maintainability** — clean code separation across layers  
- **Performance** — leveraging Go’s concurrency model  
- **Simplicity** — avoiding unnecessary complexity
